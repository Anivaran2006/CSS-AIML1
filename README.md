# CSS-AIML1

A CSS and HTML learning project for AIML students.

## GitHub Copilot Pro Model

This repository is configured to use **GitHub Copilot Pro** with the `gpt-4o` model.

To switch models in VS Code, open **Copilot Chat** and use the model picker dropdown.  
For full instructions, see [`.github/copilot-instructions.md`](.github/copilot-instructions.md).
